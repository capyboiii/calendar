Kéo thả ảnh vào đây hoặc

Thứ tự ảnh = artwork 1, 2, 3… Ảnh mẫu ít hơn 12 thì các artwork còn lại giữ nét vẽ + tông màu, ChatGPT tự nghĩ chủ thể mới (và câu chữ mới nếu ảnh mẫu có chữ).
