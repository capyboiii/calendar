Cách dùng CalForge Studio

Gõ chủ đề → bấm Bắt đầu → máy tự làm lịch treo tường để bán.

1Cài (1 lần)

Làm: bấm đúp CalForge_Studio_Setup.exe → Install → Finish. (Hiện khung xanh thì bấm More info → Run anyway.)

Được: biểu tượng CalForge Studio ngoài màn hình. Bấm vào là mở.

Máy cần có Google Chrome.

2Thêm tài khoản ChatGPT (1 lần)

Làm: bấm Tài khoản ChatGPT → Đăng nhập hàng loạt → dán mỗi dòng email | mật khẩu | mã 2FA → Đăng nhập tất cả. Nếu hiện cửa sổ bắt xác minh thì làm theo trong đó.

Được: máy dùng các tài khoản này để vẽ. Càng nhiều tài khoản càng nhanh (ví dụ 5 tài khoản ChatGPT Plus ≈ 30 cuốn/ngày).

3Làm lịch

Làm: chọn loại lịch → gõ chủ đề tiếng Anh (vd chickens) → chọn số cuốn → Bắt đầu. Rồi để máy tự chạy.

  • Wall Calendar (Blank): máy vẽ cả tranh lẫn trang lịch.
  • Wall Calendar: máy chỉ vẽ tranh, trang lịch có sẵn.

Được: các cuốn lịch khác nhau, hiện ở mục Lịch đã làm.

4Đưa lên web

Làm: bấm Đẩy R2 + xuất CSV → chờ → bấm Tải CSV. (Lần đầu bấm Khoá R2 điền thông tin người quản lý đưa cho.)

Được: 1 file CSV có đủ link ảnh của các cuốn mới, gửi file này cho người quản lý.

!Khi gặp chữ này

“Tạm hết lượt”Không làm gì, máy tự chờ rồi chạy tiếp.
Cuốn ghi “Bị dở”Mở cuốn đó → Làm tiếp.
Lỗi khácChụp màn hình gửi người hỗ trợ.
Đóng cửa sổ thì máy vẫn làm tiếp. Muốn tắt hẳn: bấm Tắt tool.
